# Data and licensing

Five things are easy to conflate in a project like this. This page keeps them apart.

## 1. The MILU dataset (not ours, not redistributed here)

MILU is [AI4Bharat](https://ai4bharat.iitm.ac.in/) and IBM's benchmark
([arXiv:2411.02538](https://arxiv.org/abs/2411.02538), NAACL 2025). The dataset itself is
released under **CC BY 4.0** (per `vendor/MILU/README.md`'s own License section) but is
**access-gated** on Hugging Face — you must request access at
[huggingface.co/datasets/ai4bharat/MILU](https://huggingface.co/datasets/ai4bharat/MILU)
before you can download it. Approval can take time; request it before doing anything else.

This repository does **not** bundle or redistribute the dataset. CC BY 4.0 would permit
redistribution with attribution, but a second, possibly-stale copy adds no value when the
authoritative gated source already exists.

## 2. The evaluation harness (`vendor/MILU`, cloned separately, MIT-licensed)

`vendor/MILU` is AI4Bharat's fork of `EleutherAI/lm-evaluation-harness`, MIT-licensed
(`vendor/MILU/LICENSE.md`). Not committed to this repo (too large relative to its value as a
copy, and it has its own upstream home) — cloned by `scripts/setup_vendor.sh` at the pinned
commit `7d8e6c9102bf44ae9f9ee84cfabefb4cb8fa2e88`, with this project's own local
modifications layered on top from `patches/`. See `patches/README.md`.

## 3. `vendor/llama.cpp` (cloned separately, MIT-licensed)

Only needed for the Sarvam-30B GGUF inference path. MIT-licensed, unmodified upstream code
(no local patch needed — confirmed via `git diff` showing zero changes). Cloned by
`scripts/setup_vendor.sh`.

## 4. This project's own code and configs (MIT, see `LICENSE`)

`pipeline/`, `configs/`, `scripts/`, `docs/`, `tests/` — this project's own contribution,
MIT-licensed per the root `LICENSE` file.

## 5. This project's own generated data (`data_raw_outputs/`, `results/`, `mlruns/`)

Verbatim per-item model outputs, the queryable results database, and MLflow run logs — all
generated by *running* the pipeline above against the (separately-obtained) MILU dataset.
This is this project's own data, not subject to the MILU dataset's license or any third-party
restriction — the reason it isn't in this repo is purely **size** (`data_raw_outputs/` alone
is 35GB+), not a licensing concern. See `.gitignore` for exactly what's excluded and why.

If you want to publish the raw outputs (not just the CSV summary tables in
`results/tables/`) for full independent auditability, options not executed by this setup:
- Git LFS, if your Git host supports large-file storage at that scale.
- Upload as a Hugging Face dataset (`datasets` library) or a Zenodo record, and link it from
  this repo instead of committing it.

## Checkpoint licenses

Every model checkpoint evaluated has its own license from its own provider (Gemma's, Llama's,
Mistral's, Qwen's, Sarvam's, OpenAI's own terms for `gpt-oss-20b`, etc.) — this project
doesn't redistribute any checkpoint weights, only records exact checkpoint identifiers and
revisions in `configs/models/*.yaml` and `docs/models.md` so results are traceable to a
specific pinned artifact. Check each model's own license before using it yourself, especially
for anything beyond research/evaluation use.
